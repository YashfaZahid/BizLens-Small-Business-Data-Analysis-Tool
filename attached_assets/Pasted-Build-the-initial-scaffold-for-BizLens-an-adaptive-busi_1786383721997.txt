Build the initial scaffold for BizLens — an adaptive business analytics 
platform for small business owners. This is a SCAFFOLDING PASS ONLY: create 
file/folder structure, placeholder pages, and API boundary. Do not implement 
business logic beyond what's explicitly listed below.

===========================================================
CONSTRAINT: REPLIT IS FOR SCAFFOLDING ONLY, NOT ARCHITECTURE
===========================================================
The app must run entirely outside Replit once scaffolded. This means:
- No Replit databases, auth, storage, or proprietary APIs anywhere in the code.
- No hardcoded credentials — all config via .env, with .env.example committed.
- Everything runs locally via standard commands (uvicorn, npm/vite dev).
This constraint applies to every section below — it is not restated per-section.

===========================================================
PRODUCT CONCEPT
===========================================================
Business owners upload CSV/Excel files with arbitrary, business-specific 
column structures. Example schemas that must all be supported:

  Business A: Date, Product, Qty, Selling Price, Purchase Price
  Business B: Order Date, Service, Client, Hours, Amount Received
  Business C: Invoice #, Customer Name, Item, Units Sold, Net Amount, Supplier Cost

Eventual pipeline (build only the placeholder structure, not the logic):
  Upload → Understand columns → Generate analytics → Answer natural-language questions

Eventual query flow (interfaces only, no implementation):
  User question → AI parses intent → structured analysis request → 
  backend computes from actual data → AI explains the result in text
  (The LLM never performs numeric calculation — it only interprets 
  questions and explains backend-computed results.)

===========================================================
TECH STACK
===========================================================
Frontend: React, TypeScript, Vite, Tailwind CSS, React Router
Backend:  Python, FastAPI, Pandas, openpyxl — must run standalone via 
          `uvicorn app.main:app --reload`
Database: Supabase PostgreSQL only (not SQLite, not Firebase, not MongoDB)
Storage:  Supabase Storage (architecture only — no upload-processing pipeline yet)
Auth:     Supabase Auth (config structure only — no working auth flow yet)

Required env vars (.env.example, no real values):
  SUPABASE_URL=
  SUPABASE_ANON_KEY=
  SUPABASE_SERVICE_ROLE_KEY=
  (plus frontend API base URL, and a placeholder AI provider key var)
